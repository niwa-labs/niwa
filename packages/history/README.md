# @niwa-labs/history

Reading a session's transcript through its harness's reading side: read with a bound harness (every record, or a digest or a brief in windows), plain-text search over the records, and a description of how much of a transcript was actually read. The `history` plugin lists the sessions the reading sides hold (`history.list`), reads and searches a transcript (`history.read`, `history.search`), and watches a session of any harness as it grows and records how far its checklist is, when it pauses and when it ends; the transcript itself is never written into the journal. `/records` holds the schemas of the queries, the records and the actions, and `sessionEnded(session)`, the query of the end of one watched session. `/flow` gives workflow scripts `readSession`, which reads a transcript in windows, and `untilSessionEnded`, which waits for a watched session to end; each is a step of the script.
